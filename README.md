# Jamtopia — Animated Multi-Page Website

Responsive static website concept for Jamtopia. The homepage cards now lead to dedicated activity pages, with shared styling and navigation across the site.

## Pages
- `index.html` — homepage and activities overview
- `atv-rides.html` — ATV rides
- `paintball.html` — paintball
- `drive-in-movies.html` — drive-in movies
- `dining.html` — restaurant and lounge
- `group-outings.html` — group outings and entertainment enquiries
- `go-karts.html` — go-karts, clearly marked Coming Soon

## Preview
Extract the ZIP, then open `index.html` in a browser. For best results, use VS Code Live Server.

## Before publishing
Verify contact details, activity availability, prices, hours, safety requirements, booking methods and business wording directly with Jamtopia. No pricing, hours or booking guarantees have been invented in the activity pages.
